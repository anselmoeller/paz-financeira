Preguntas frecuentes

Respuestas sencillas para empezar.

¿Puedo registrar suscripciones y compras a plazos?

Sí. Puedes registrar gastos únicos, cuentas mensuales, suscripciones y cuotas.

¿Incluye notas y tareas?

Sí. Puedes escribir notas, escanear texto, grabar audio y organizar listas de tareas.

¿Puedo compartir informes en PDF?

Sí. Hay opciones de PDF para finanzas, notas, tareas e ingresos.

¿Debo pagar para usarla?

Existe una versión gratuita con anuncios. Pro añade funciones y elimina la publicidad.

¿Cómo funcionan las copias locales?

Puedes crear y restaurar archivos locales protegidos. Guarda el archivo y el PIN utilizado.
